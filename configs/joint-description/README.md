# Authored new joint-description studies

SPDX-License-Identifier: CC-BY-4.0

R01.json through R22.json are editable new study recipes. They are not historical
result files or canonical execution manifests. Copy one to explicit external
working storage, review the scientific choices and follow
[the authoring guide](../../docs/v1.0/joint-description-experiments.md).

The family identifier selects the domain assay; the recipe declares its actual
question, preparations, independent cohorts, actions, receivers, horizons,
description candidates and economics. Identities, recursive operations and
source-bound execution records are derived by the public API.

Physical-cohort families require their declared raw observations. See the [programme results](../../programmes/shared-records/joint-description-results.md) for the original assessments and remaining input requirements.
