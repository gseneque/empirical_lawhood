# R01–R22: scientific family census for the new experiments

This catalogue defines the scientific meaning of all 22 reauthored families.
Use [experiment authoring](joint-description-experiments.md) for commands and
[physical/native inputs](joint-description-inputs.md) for strict raw schemas and
native prerequisites. The original family labels preserve scientific themes;
old outcomes, selected events, fitted coefficients and result counts are not
experiment inputs. Nothing in this catalogue claims that the new experiments
have been executed or that the hypothesis has been confirmed.

## The common question and its layers

For a declared family of preparations, interventions, receivers and horizons,
compare a finite menu of descriptions by held-out prediction quality, supported
action selection, safety constraints and explicit economic prices. Does a
smaller useful joint description remain available, or does further decomposition
require paid interface information, retained memory or increased error? The
preprint response-law/control question is one component of this comparison.

| Layer | Responsibility | Scientific consequence |
| --- | --- | --- |
| Authored specification | Independent units and split, actions, horizons, receiver targets/error promises, description menus, economic prices | The question and denominator exist before evaluation |
| Scientific contracts | Separate predictor and outcome records, complete trial keys, explicit unsupported/failed rows | Outcomes and evaluator diagnostics cannot become forecast operands |
| Domain instruments and mechanisms | Actual substrate equations, preparations, receivers and reusable candidate calculations | Different domains can share comparison methods without replacing their scientific substrate |
| Methods | Calibration-only fitting or a declared fixed mechanism; frozen predictions and actions; complete-census evaluation | Fitting and action selection do not see evaluation outcomes |
| Execution and adapters | Typed effects, actual engine/backend contact, pinned raw input bytes, custody and recovery | Remote/local resources and external formats do not own scientific verdicts |
| Recursive composition | Preparation, acquisition, fit, forecast, evaluation acquisition and assessment connected by typed dependencies | Upper mechanisms can supply descriptions or preparations to unchanged lower mechanisms |

A small raw-information description can still require a large numerical
calculation. State/interface/memory prices and calculation costs must therefore
remain separately interpretable. For regression-based physical/native families,
product/interface features are declared derived coordinates of existing inputs;
they do not manufacture new independent measurements. Their comparison is a
finite model-class and information-accounting experiment, not an information-
theoretic proof of intrinsic nonseparability.

R01 includes an independent-branches negative control against universal
irreducibility. R04 and R05 retain conditional nonentries. R06 preserves
operator/directional diagnostics. R09 checks absolute-state support. R12 retains
numerical refinement disagreement. Recorded-source families preserve their
archive exposure. These controls allow a finding of sufficient decomposition,
insufficient evidence or no useful candidate, rather than forcing a smallest
joint description to exist.

## Default menu overview

physical/native time horizons are in seconds; matrix horizons are in the
model's dimensionless Langevin time. Independent calibration/evaluation counts
are authored by the family presets and can be changed before a run is issued.

For R03–R12, each independent root draws its preparation uniformly from the
authored `preparations` list using a separate stream keyed by family, seed,
calibration/evaluation split and root identity. This is a random mixture, not
an exactly balanced allocation; a finite cohort need not contain every
preparation. Root assignment is unchanged when the shared runtime executes
one root per worker, batches several roots, or restores completed subwork.
The preparation selected for each row is retained as `context.preparation`,
with codes 0–3 denoting `product`, `x-factor`, `y-factor` and `disordered`.

## Family specifications

Each section states the inherited theme, the new question, its executable
preparation/response construction, the meaning of candidate descriptions and
its interpretation limit. Source links identify reusable implementation owners;
they are not references to historical result tables.

### R01 — Analytical RC information and factorization

**Preprint theme:** Does an identical reduced circuit observation conceal a later response difference?

**New question:** When does mean-voltage compression lose control-relevant contrast, and when do independent branch laws already suffice?

An independent root contains a paired preparation with identical observed mean and different branch-voltage contrast. Two uncoupled RC branches share the chosen source voltage; their distinct known relaxation times expose the information lost by mean-only compression.

Full branch voltages, mean-only reconstruction, mean plus measured contrast, and a finite pre-decision mean history supply the same response law. The independent-branches candidate is an explicit control: the two physical laws can compose without an irreducible dynamic interface.

Candidate IDs: `joint`, `partitioned`, `interface`, `memory`, `independent-branches`. Default independent roots: 16 calibration and 32 evaluation.

Reusable owners: [circuit definitions](../../src/empirical_lawhood/domains/circuits/joint_description.py), [RC information calculus](../../src/empirical_lawhood/domains/circuits/rc_information/analytic.py), and [RC ladder MNA](../../src/empirical_lawhood/domains/circuits/rc_ladder/mna.py).

**Scope and prerequisite:** A failure of mean-only compression does not prove physical nonseparability. The independent-branches control can retain enough information while remaining factorizable. Pair members are nested receivers, not two independent roots.

### R02 — Coupled RC preparation and history depth

**Preprint theme:** Do near-matched observed histories permit adverse hidden-state response or decision differences?

**New question:** For coupled RC preparations, which finite information descriptions meet receiver accuracy and control utility at each horizon?

Fresh component metrology and initial voltages instantiate a coupled eight-cell RC ladder. The lower operator is built by modified nodal analysis. Causal history is produced by forward preparation before the decision boundary.

Compare all present voltages, two partition means, means plus interface endpoint voltages, and lagged mean observations. Each description reconstructs inputs to the same known linear law; history rank and conditioning are retained.

Candidate IDs: `joint`, `partitioned`, `interface`, `memory`. Default independent roots: 16 calibration and 32 evaluation.

Reusable owners: [circuit definitions](../../src/empirical_lawhood/domains/circuits/joint_description.py), [RC information calculus](../../src/empirical_lawhood/domains/circuits/rc_information/analytic.py), and [RC ladder MNA](../../src/empirical_lawhood/domains/circuits/rc_ladder/mna.py).

**Scope and prerequisite:** These are information-description comparisons, not a claim that every reduced arm executes a smaller numerical state space. A rank-deficient memory reconstruction is not silently granted full-state information.

### R03 — Structural feasibility and joint-description scope

**Preprint theme:** Does the finite six-matrix design produce the recurring structural regimes required for dependent tests?

**New question:** Which preparation and action scope admits a useful geometry description, and where does removing cross-sector information move its prediction error?

Product, single-factor and disordered preparations instantiate the actual q=2 six-matrix model with independently authored perturbations. The action changes the X coupling; the response remains a full native Langevin trajectory.

Local sector coordinates, local coordinates plus measured cross-sector interfaces, causal local memory and the complete two-sector phase state predict structural gaps, relative orientation and admission indicators.

Candidate IDs: `local`, `local-interface`, `local-memory`, `joint`. Default independent roots: 48 calibration and 32 evaluation.

Reusable owners: [matrix family composition](../../src/empirical_lawhood/domains/matrix/joint_description/experiments.py), [native scientific dynamics](../../src/empirical_lawhood/domains/matrix/joint_description/native.py), [instruments](../../src/empirical_lawhood/domains/matrix/joint_description/instruments.py), and [reduced mechanisms](../../src/empirical_lawhood/domains/matrix/joint_description/mechanisms.py).

**Scope and prerequisite:** The structural domain is explicitly q=2. This is a finite feasibility experiment and supplies no automatic qualification for dependent response or control claims. All failed and nonadmitted roots remain in the denominator.
