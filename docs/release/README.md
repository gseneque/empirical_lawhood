# Release scope and evidence

SPDX-License-Identifier: CC-BY-4.0

The v1.0 software scope includes 22 editable experiment recipes and verified
primary CPU results for 20 families. R14 and R16 await qualifying physical
measurements. R17 and R22 have CPU results and await separate GPU qualification.
The four outstanding scientific tasks are follow-ups to v1.0. [Study findings](../../programmes/shared-records/joint-description-results.md) · [Family census](preprint-recursive-migration.md)

Software acceptance covers the public contributor workflows, local and remote execution, and portable and installed checks on the selected source. The maintainer accepted the local preparation, remote native execution and returned partial records from the owner-stopped Rubisco M1 and M50 runs as software-placement evidence. The scientific records retain their original incomplete outcomes.
