## Implemented and deferred boundaries

Every row uses `joint-description.development`, an authored specification, separate calibration/evaluation cohorts, a complete derived scientific graph, typed predictor/outcome separation, actual domain science or a raw/native adapter, shared execution/custody and retained-result reading/recovery. There is no family-specific scheduler and no call-through to an old campaign.

The graph freezes the fitted response law before evaluation preparation, retains forecasts/action choices before evaluation acquisition, and assesses complete independent-root denominators. Negative, unsupported, missing and unsafe outcomes remain meaningful terminal evidence. Simulator observations cannot substitute for missing physical observations.

Twenty primary CPU studies completed the six-operation lifecycle. Their original workers accounted for 680 calibration and 484 evaluation assignments, including 874 unsupported held-out receiver rows. Optical-mirror R14 and divertor R16 remain at input preparation. R17 and R22 have CPU results and await separate remote GPU comparison. The dated programme record gives each scientific finding and binds the original assessments. [Scientific results](../../programmes/shared-records/joint-description-results.md) · [Backend qualification](../v1.0/cpu-and-gpu.md)

For physical families, supply newly selected raw cohort data under [the documented schema](../v1.0/joint-description-inputs.md). A missing cohort blocks that run. Do not replace the missing observations with fixtures and call the scientific experiment complete.

Economic interpretation retains state, interface, memory and authored forecast-construction estimates separately. A useful minimum is conditional on the finite menu, prices, reuse, targets, receiver errors and safety constraints. Independent preparations are the sampling unit; action, horizon and receiver panels remain nested.
