# Public sources and external custody

SPDX-License-Identifier: CC-BY-4.0

This guide gives instructions for public source selection and guarded external custody.
It separates source acquisition from native scientific qualification.
Use it to select a programme source and identify acquisition prerequisites.

Source declarations live beside their programme workflows. They select public endpoints, finite members, schemas and transfer bounds. They contain neither experimental payloads nor a publisher checksum. The storage profile supplies the external root. The exact downloaded bytes, SHA-256 values, time and source selection are recorded in a guarded receipt.

The [NREL inverter qualification assessment](../../programmes/energy/electricity-grids/records/nrel-inverter-qualification.md)
records a newer authentic public reference and the physical action journal it
does not contain. The prospective NREL physical route is outside first-release scope. The
assessment is a source decision, not an acquisition declaration or candidate
route.

The [Glenn 2026 archive assessment](../../programmes/foundations/measurement-and-response/records/glenn-2026-qualification.md)
records a distinct official public retrospective source. Its [strict local
quick start](../../programmes/foundations/measurement-and-response/workflows/laser-archive-inspection/guide.md) now previews the pinned release and
validates a researcher-held ZIP through the one CLI. It is an outcome-visible
dataset transform without a guarded custody/authorization handoff or
prospective physical intervention claim.

The [Grid2Op held-source assessment](../../programmes/energy/electricity-grids/records/grid2op-qualification.md)
records an authentic excluded chronic and the installed native action/receiver
check. The installed CLI accepts an explicit local development selection.
A prospective route still needs a newly qualified chronic roster and a selected campaign provider.

## Public source acquisition

The [FAIR-MAST guide](../../programmes/energy/fusion/workflows/fair-mast-source/guide.md)
owns its public selection, preview, acquisition, recovery and design-input commands.
Its [editable declaration](../../programmes/energy/fusion/workflows/fair-mast-source/fair-mast-level2.json)
selects bounded members and has separate source/custody authority requirements.
An acquisition receipt does not establish scientific fitness or permission for later use.
