# Prepare a further recursive scientific inquiry

SPDX-License-Identifier: CC-BY-4.0

Investigate whether one operation supplies a condition needed by another inquiry.
Test that connection, then assess the later scientific result separately.
The shared authoring layer records this progression within a finite selected wave.

The working scientific purpose is **the recursive construction of scientific knowledge and capability**.
The [worked workflow](recursive-inquiry.md) supplies an authoring interface for that purpose.
Its numerical examples establish development findings within their declared models.
The [completed prerequisite results](../../programmes/foundations/measurement-and-response/records/recursive-prerequisite-results.md) preserve
their numerical findings, provenance and limits. A further scientific study
needs separately selected questions, eligible evidence and justified claims.
This readiness map selects no new programme or native execution.

## Start with available knowledge and capabilities

The [battery protocol](../../programmes/energy/battery-charging/workflows/recursive-battery/battery-protocol.md) selects a bounded example.
It investigates what a later voltage calculation needs from an earlier preparation.
The simulator, Chen2020 parameters and full-state restart capability are existing knowledge.
Their presence does not establish the adequacy of a particular supplied checkpoint.

| Stage | Scientific question and actual product | Evidence role and limit |
|---|---|---|
| Initial stock | PyBaMM SPMe, fixed parameter source, declared current words and restart representation | Known numerical capability; no physical sensor or new law is implied |
| Wave A investigation | Does the exact state and causal input ledger support the assigned hold continuation? | Assessed procedure evidence from two histories nested within one exposed preparation |
| Alternative | Is the observable SOC/capacity/temperature representation adequate for the same voltage consumer? | Separate adequacy assessment; retain adequate, inadequate or unevaluable findings |
| Retained contribution | Actual procedure, assessments, native products, source binding and producing receipts | Non-promotable design operand; exact custody travels with it |
| Wave B supply | Apply the procedure to a new exposed preparation and changed future words | New instance products and continuation checks; earlier hold evidence does not qualify changed words |
| Consumer admission | C1 permits full numerical state; C2 permits observable channels | Distinct consumer contracts; software types alone do not prove supply |
| Further product | Signed equal-charge history contrast and current proportionality defect | Separate numerical findings under the frozen tolerance controls; no population inference |
| Joined use | Do both consumers' requirements and the intended use succeed together? | Retain incompatible admission and negative joined results, even when C1 succeeds |

Wave B reuses the procedure, rather than Wave A's physical state.
Its source instance, cutoff and complete assigned census remain explicit.
The portable packet permits later authoring without accessing the producer directory.
It supplies neither issue authority nor permission to reveal protected outcomes.

## Map a new scientific design to existing owners

| Required work | Existing shared owner | Additional work when the selected question requires it |
|---|---|---|
| Requirements, quantities, clocks, uncertainty and falsifiers | Scientific requirement and connection records | Specify the actual scientific meanings and admissibility criteria |
| Partial programme, competing suppliers and selected finite wave | Recursive study draft and campaign lineage | Declare missing premises and meaningful terminal stops |
| Typed source, allocation and array operands | Existing source resolution and bounded input contracts | Implement an authentic source adapter if the required source is absent |
| Scientific operation and native semantics | Registered config, method, executable factory and provider port | Add a bounded domain operation at this seam |
| Investigation, supply and joined assessment | Registered assessment records and pure projections | Implement an independent falsifier for the proposed scientific connection |
| Lowering and execution | Existing candidate compiler, plans and local scheduler | Reuse these owners; a new family does not need another scheduler |
| Exact products and later contribution reuse | Guarded artifacts, completion receipts and contribution callbacks | Describe actual products and their supported successor design |
| Prospective study | Standard entry package, source/exposure qualification and ordinary lifecycle | Obtain genuine eligible sources and applicable issue, execution and reveal authorities |
| Complete results and recovery | Frozen task census, receipt reader and durable contact custody | Retain failed, refused, unevaluable and uncertain outcomes |

The [extension guide](../development/extending-the-engine.md) gives the registration and generator order.
Code-owned factories declare contribution semantics; configuration selects registered operations and links.
Configuration cannot select arbitrary executable code or construct scientific authority.

## Keep the readiness stages distinct

| Stage | Supported boundary | Remaining requirement |
|---|---|---|
| Authoring and software conformance | Finite shared graphs, strict operands, custody and lifecycle checks | Verify each changed operation on its selected source |
| RC and battery development | Actual exposed numerical acquisitions within their frozen protocols | Inspect complete retained results and source identities |
| General prospective machinery | Public standard lifecycle with separate qualified-parent rules | Software fixtures are conformance evidence; they are not a real qualification study |
| Materials programme | Partial questions about material A, a device and material B | Authentic fabrication, instrument response, metrology, resolution and qualification sources remain absent |
| Physical or population result | No automatic claim follows from the numerical examples | Select and execute a genuine study with suitable independent units and uncertainty treatment |
| Reduced acquisition cost or broader scientific advantage | No comparative advantage is established by a longer chain | Predeclare alternatives and include failed search, compatibility and qualification costs |

For a new study, freeze the actual source, information schedule, assignments and negative outcomes.
Declare which existing commitments remain applicable and which need additional qualification.
A different seed label does not make exposed evidence fresh.
A correctly implemented workflow can finish with a scientifically negative or unevaluable result.

Read [experiment design](designing-and-running-an-experiment.md), [configuration](configuration.md)
and [results and failures](results-and-failures.md) before selecting execution inputs.
The original paper assets and frozen scientific packages remain separate from these maintained instructions.
