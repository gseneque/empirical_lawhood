This overview identifies the programme's question, evidence and available operations.
It keeps scientific findings separate from software availability.
Choose a study below before selecting a run guide.

## Scientific question

Which material descriptions and preparation conditions could support superconductivity at room temperature and ordinary pressure?

## Findings and unresolved questions

The retained work separates descriptions of known materials, analytic
reference calculations, synthetic method checks and unresolved physical inputs.
None of these routes establishes a room-temperature superconductor or a usable
preparation procedure.

The [historical review](records/ambient-pressure-material-historical-review.md)
records the original material investigations. The current five-material route
checks supplied inputs; it does not run a physical synthesis or qualify the material.
