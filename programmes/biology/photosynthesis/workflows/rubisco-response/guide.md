# Assess paired Rubisco kinetics through the public experiment route

SPDX-License-Identifier: CC-BY-4.0

This workflow computes paired WT/mutant endpoints from explicitly supplied rates.
It retains every case, scenario, failed or unknown alternative and independently
assesses the joint decision.
Its conditional result leaves biological prediction and computational benefit
as separate unresolved requirements.

For the retained initial Gp WT/I95M model, use the narrower
[initial joint-root workflow](initial-root-v1.md). It accepts missing relative
operands, retains their scientific prerequisites and performs no molecular
acquisition. Its optional supplier branches do not select this guide's broader
comparative response-study requirements automatically.

For the selected local formation investigation, use the
[paired preparation and response specification](preparation-response-v1.md).
It defines the checkpoint, diagnostic, withheld-response and destination-assessment sequence.
Use its registered `rubisco-preparation-response-design` consumer and original-input preparer before the shared inquiry lifecycle.
Its retained-prefix continuation uses `continue-prefix`; findings use the registered `rubisco.preparation-response` panel and original returned wave directory.
The [workbench guide](../../../../../docs/using/research-workbench.md) describes the six-question display, exact records and separate operational observations.
The maintained operator recipe composes those existing services; it does not replace the recursive architecture.

Its [implementation and acceptance register](preparation-response-v1.md#implementation-and-retained-acceptance)
distinguishes implemented extensions and component checks from pending complete installed/deployment acceptance.
The original M50 return contains five I95M evaluations. WT did not enter, so the paired prefix has no completed result. The [molecular audit](../../../../../docs/release/rubisco-molecular-remediation.md) sets the construction and force requirements for a new M50 attempt.
