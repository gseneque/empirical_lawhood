## Fixed receiver and physical challenge

The formation coordinate is

\[
\xi=d(C3,H3)-d(H3,O_{\mathrm{KCX}}).
\]

The existing formation-coordinate owner derives the physical atom roles and complete natural-mass binding.
At each genotype's initial checkpoint, let \(u\) be the normalized Cartesian gradient of \(\xi\).
Let \(v\) be the normalized orthogonal component of the gradient of the corresponding sum of distances.
Set \(w=(u+v)/\sqrt{2}\).
The same fixed \(u,v,w\) apply at that genotype's initial and later checkpoints.
Matched chemical roles define the WT/I95M comparison.
This projection uses the original Cartesian frame and adds no constraints or mass weighting.

With native energy gradient \(g(x)\), the signed receiver is \(R(x)=-u^Tg(x)\), in hartree/bohr.
For \(K=\nabla^2E\), estimate the complete action through

\[
K_hu=\frac{g(x+hu)-g(x-hu)}{2h}.
\]

The default derivative scales are 0.02 and 0.01 bohr.
The finite challenge is \(x'=x+\alpha w\), with \(\alpha=0.2\) bohr, approximately 0.106 Å.
This amplitude is ten times the larger derivative displacement.
It tests a native mixed chemical displacement with the original full operator.
It is not an analytical restraint update.

Freeze the local prediction before each challenge:

\[
\widehat{\Delta R}=-\alpha w^T K_{h/2}u,
\qquad
e=R(x')-R(x)-\widehat{\Delta R}.
\]

## Prospectively declared transferred protons

The complete molecular screen uses original Amber covalent bonds for its
nonbonded contact census. A transferred QM proton can create a different
covalent bond: the declared O–H construction distance is 0.98 Å, below the
1.00 Å nonbonded gross floor. Declare those exact new bonds in
`MolecularGeometryPolicy.reactive_hydrogen_bond_pairs` before publishing the
selected preparation. The default is empty; the frozen M50 `keto-hie` /
`AS_CONSTRUCTED` case needs no exception.

For an authenticated `representation`, `site`, `prepared` and selected `seed`,
derive the pairs from the **declared chemical graph**, never from observed
distances or results:

```python
from dataclasses import replace

assert seed.site == site.identity and seed.protocol == prepared.protocol.identity
assert site.path.representation == representation.identity
graph = next(g for g in prepared.protocol.graphs if g.identity == seed.graph)
original_bonds = {(b.first, b.second) for b in representation.bonds}
pairs = set()
for bond in graph.bonds:
    first, second = graph.atoms[bond.first], graph.atoms[bond.second]
    if first.cap or second.cap or (first.atomic_number == 1) + (second.atomic_number == 1) != 1:
        continue
    pair = tuple(sorted((site.core_atom_indices[bond.first], site.core_atom_indices[bond.second])))
    if pair not in original_bonds:
        pairs.add(pair)
geometry_policy = replace(
    prototype.molecular.geometry_quality,
    reactive_hydrogen_bond_pairs=tuple(sorted(pairs)),
)
```
