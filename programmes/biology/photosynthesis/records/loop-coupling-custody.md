## Retain first, assess independently

The additive [raw-return seam](../../../../src/empirical_lawhood/adapters/methods/rubisco_insilico_free_energy/raw_coupled_return.py)
accepts the actual returned scalar energy and native gradient. The exact request
binds protocol, prepared material, full physical coordinates, producing
provenance, atom denominator, units and coordinate frame. Its three output slots
are committed before contact by the existing native-subwork owner.

It publishes both complete operands, then a typed unassessed return record,
before invoking any scientific guard. Lossless gzip of no-pickle NPY uses the
existing uninterpreted raw-source custody route. Dtype/endian, observed shape,
original strides, source type, full byte identities and exact materialization
manifests are retained. The serializer preserves signed zero and nonfinite bit
patterns and makes no dtype cast. Buffer sizes bound working memory without
thinning the scientific operands. Primitive numeric types outside the selected
real floating interpretation remain captured but unsupported. Ambiguous
containers remain explicitly uncaptured; expected zeros are never substituted.

A separate assessor reads the authentic complete retained bytes through a
manifest-resolving port. It checks the physical element denominator, finite
values and any explicitly selected numerical magnitude criterion, preserving
the adverse operand census. A supplied assessment is rechecked against those
same actual bytes before consumer admission. Numerical integrity establishes
neither acceptable geometry, derivative consistency, chemical adequacy nor
mutation-to-kinetics prediction.

A publication failure propagates to the existing AR3 custody owner, leaving
partial output/uncertain contact and refusing replay. Captured scientific
negatives may complete operationally; unsupported capture retains the omitted
output and actual error. The caller separately closes the actual cost window.
This seam introduces no scheduler, contact launcher or blanket retry.
