## Scientific question

Which observations help select a useful intervention in an unfamiliar biological context?

## Findings and unresolved questions

The retained neuronal-record analysis distinguishes an available suitable
action from a dependable selection procedure. Separate gene-expression work
examines intervention prediction and the effect of treating nested cells as
independent biological replicates.

Electrical stimulation and gene intervention remain distinct studies. The
current Brian2 workflow is a numerical neuron diagnostic. It does not reproduce
the physical neuronal recordings or provide a gene-expression analysis pipeline.
